# Security policy

## Reporting a vulnerability

Report security vulnerabilities privately, not through a public issue or pull request.

Prefer [opening a private vulnerability report on GitHub](https://github.com/danielroe/forges/security/advisories/new). Alternatively, email [daniel@roe.dev](mailto:daniel@roe.dev).

Include the affected version, a description of the issue, and reproduction steps or a proof of concept if available.
